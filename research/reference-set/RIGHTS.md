# 图像来源与版权说明

仓库根目录的 MIT License 只适用于 QiuXu-Tech 原创内容，不对第三方绘画作品的图像文件重新授予 MIT 权利。

本参考集逐件筛选 Wikimedia Commons 标为 CC0 或 Public domain 的原作复制图，以及克利夫兰美术馆 API 中明确标记 share_license_status=CC0 的图像。每件作品都在 catalog.json 中记录了 source_record_url、original_image_url、image_license 和 license_url；本地研究副本保留 preview_sha256 校验和。

- CC0：Creative Commons Zero 公有领域贡献，详情 https://creativecommons.org/publicdomain/zero/1.0/
- Public domain：Commons 文件页标示的公有领域复制图，不等同于图像上传者一律使用 CC0。详情 https://creativecommons.org/publicdomain/mark/1.0/
- 商业使用或跨国发布前，应核对原始馆藏/Commons 文件页及所在地法律；本项目不作全球适用的权利担保。
- 部分 Commons 候选采用 CC BY-SA 等需要署名和相同方式共享的许可，本批有意排除，降低混合授权复杂度。
- 图像的原始馆藏、扫描、展陈说明和第三方照片可能有不同权利；明确标识来源不等于美术馆认可本项目。
- 如果原来源许可或作品身份被更正，应复核后修订或移除对应图像。
