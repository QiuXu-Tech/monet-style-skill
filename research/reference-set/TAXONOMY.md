# 参考集分类规则 v0.2

本集按四个维度分类：创作年代、题材、系列／重复母题、作品标题中的光照天气。分类是检索工具，不等于艺术史专家鉴定或视觉特征量化；一个作品只能有一个主导题材，但可以具有一个系列／母题标签和多个标题条件标签。

## 系列与重复母题

跨年代的重复题材不等同于严格意义的同一连作，例如 1880 年代的干草堆不能自动归入 1890—1891 年的同一组连作。下列类别均为研究对照用分组。

- grainstacks-1890s：1890—1891 年干草堆／麦垛光色对照（6 件）

- waterloo-bridge：滑铁卢桥题材／系列（4 件）

## 作品标题中的光照与天气

**只做文字索引。**标签来自标题或采集元数据，没有从画面中推断具体天气；未标记不代表实际作品没有该特征。

## 来源与不确定性

年份、馆藏和作品名称继承来源的元数据，部分条目由 Commons 的美术馆分类指示藏所，并非均已逐一以官方馆藏号复核。JSON 中保留 date_basis、holding_institution_basis、source_record_url 等出处。图片许可也逐件保留，Public domain 和 CC0 是不同的权利标识；根目录的 MIT 许可不延伸至第三方图片。

原图扫描文件可能对应同一作品的多个数字版本，目前主要通过 Commons page ID 去重，尚未对所有画面做图像级重复检测。
