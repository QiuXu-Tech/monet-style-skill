## 一、研究结论

**稳定性不是一个开关，而是需求、参考素材、模型条件、版本复现和结果验收共同形成的能力。** 一段稳定的提示词，只能约束输入的一部分；一张漂亮的演示图，也不能证明换题材、换种子后仍然稳定。

适合本项目研究的输入分工是：

```text
用户要求 P ─────────────────→ 主体、数量、动作、关系与禁改项
内容原图／布局 C → 结构预处理 ─→ ControlNet（有内容原图时）
莫奈风格参考 S → 图像编码 ─────→ IP-Adapter 的风格相关层
参考内容描述 q → 可选特征相减 ─→ 减弱 S 中不需要的场景信息
                                  ↓
                              候选图片
                                  ↓
            内容 + 结构 + 画风 + 参考内容泄漏：分别验收
```

q 描述 **S 中画了什么**，不是用户希望画出的 P；结构条件来自 **C**，不是为了省事从莫奈风格参考 S 中提取。上述分工旨在减少错误的条件来源，不代表模型内部已经实现严格解耦。[S1–S7]

## 三、InstantStyle 的两种机制

### 3.1 内容特征相减

概念式为：

```text
参考表示 = CLIP_image(S) − α × CLIP_text(q)
```

固定实现先做相减，再把结果送进图像投影模块。它试图减少参考场景的语义影响，不是获得一个艺术史意义上纯净无杂质的“莫奈向量”。向量算术是模型特征空间中的经验方法，不是严格的风格分解定理。[S1, S2]

前提是图像与文本特征处在兼容的 CLIP 空间，维度一致，并且属于此实现支持的**全局表示**。IP-Adapter Plus 使用 patch hidden states，不能直接照搬相减公式。必须区分三件事：IP-Adapter Plus、InstantStyle 仓库里的 infer_style_plus.py，以及独立的 InstantStyle-Plus 项目。[S2, S3]

q 应描述参考图的池塘、桥梁、人物等内容，不应把“莫奈、油彩、破碎笔触”也作为要剥离的内容。若目标图和参考图都含桥梁，也不能把桥梁粗暴列为生成禁词；可优先实验仅指定层注入、降低相减强度或更换参考图。以上是本项目的待验证建议。

### 3.2 只在特定网络位置注入画风

InstantStyle 针对 SDXL 使用 `up_blocks.0.attentions.1` 作为风格相关注入位置；加入 `down_blocks.2.attentions.1` 则引入更多布局相关影响。这是相应模型上的经验控制位置，并非所有网络都有一个完全纯净的“风格层”。[S1, S2]

原生 Diffusers 可以用逐块权重表达同类选择：

```python
# SDXL 候选配置；s 必须实测，不是质量保证。
scale = {"up": {"block_0": [0.0, s, 0.0]}}
```

但 `neg_content_prompt` 是研究中的 InstantStyle 自定义封装参数，不能假设传给任意原生管线或封闭图片 API 就会生效。需要显式特征计算与兼容性检查；后端不支持时，应明确标注未启用，而非静默降级。[S2, S4]

此外，图像注意力是以加法合入文字路径，概念关系为 `H_text + λ × H_image`。λ 不是“画面中风格占百分之多少”，λ=1 也不代表文字路径被关闭。[S5]

## 四、ControlNet 的职责与边界

### 4.1 布局不能来自错误的图片

官方组合示例分别读取风格图与内容图，并从内容图提取 Canny。示例使用图像强度 1.0、结构强度 0.6、30 步、seed 42，但并没有启用内容特征相减。因此，这只是组合调用的示范，不证明两种去内容机制都已开启，更不证明这些参数对莫奈最优。[S6]

结构保留与语义正确必须独立检查。轮廓图可以提供建筑布局，却不能保证物体数量、人物动作或现代列车属性都正确。InstantStyle-Plus 因而把空间布局和全局语义安排为不同控制路径。[S7]

### 4.2 强度与作用时段分开研究

Diffusers 先按条件强度缩放 ControlNet 输出，再把它作为残差加入 UNet；`control_guidance_start/end` 控制其作用的采样步区间。这不是“原图保留比例”。[S9]

针对莫奈的候选假设是：过强的细碎边缘控制可能压制轮廓的绘画性概括；缩短控制持续阶段，可能给后续笔触留出空间。**这是实验假设，不是已确认的最佳策略。** 应比较不控制、全程 Canny、提前结束 Canny 和相应 Depth 控制，而不是一次性把所有参数一起调动。

Depth 与 Canny 需要各自匹配的模型权重、预处理和尺寸对齐。不能把深度图送进 Canny 权重，就称为合法的深度对照实验。[S9]

### 4.3 不把所有“保内容”组件一次加入

InstantStyle-Plus 还组合内容反演 latent、Tile ControlNet、全局语义适配器和 CSD 相关信号。其示例的附加 style/content guidance 默认均为 0，源码也提示启用会增加内存开销。论文讨论的组件，并不必然在默认演示中启用。[S7]

CSGO 是另一条有价值的内容／风格双分支路线，但需要专用权重；它适合后续比较，而非当前轻量 Skill 的默认依赖。[S8]

## 五、完成的符号接口检查

对象：InstantStyle `6b40588e263c958653353ec24eb7eb990cfa3da7` 中的 `IPAdapterXL.generate`。通过 AST 提取方法，在固定源码校验后使用符号张量、模拟 encode_prompt 与模拟管线检查参数流和批次维度。没有执行真实 torch 运算、CLIP 编码或图片生成。

| 用例 | 实际观察 | 含义 |
|---|---|---|
| 不相减、num_samples=2 | 形状路径成立 | 正常对照 |
| 文本相减、num_samples=1 | 相减输入为 (1,1280) | 单图对照 |
| 传入预计算 neg_content_emb | get_image_embeds 收到 None | 固定源码分支忽略该输入 |
| 文本相减、num_samples=2 | 拼接形状变成 (2,77,2048) 对 (4,4,2048) | 相减文本扩批与后续重复叠加，符号执行出现不匹配 |
| guidance_scale=5.0 | 经 kwargs 正常传递 | 不能因为未显式写在形参表中就误报丢参 |

5 项观察断言均满足，其中 2 项是**上游行为风险被复现**，不是“上游 5 项功能验收通过”。结果只覆盖固定源码与单参考图模拟条件。真实环境的异常类型和运行表现仍需之后验证。[S2]

工程建议：学习方法与复制封装分开。优先基于受支持的原生接口实现最小逻辑；若采用旧封装，应先补参数传递、数量与批次的回归测试。本轮没有改动或向第三方仓库提交修复。

## 六、从 Agent Skill 项目提取的工程原则

hand-drawn-styles 用单一配方来源、占位符和参考图校验降低输入漂移，还把候选输出与独立验收分开；其 Skill 本身明确不直接生图。mono-color 则把主体、意图、视觉约束、受控变化和质量门槛分阶段组织。[S10, S11]

对本项目最有用的是：明确参考图角色；锁定经过验证的风格规则与版本；允许场景、天气和题材变化；内容和风格分别验收；保留失败样本和重试记录。

应锁定“画法”，而非强迫所有作品具有同一个调色板、地平线或睡莲题材。需要纠错时，先识别是内容、结构还是画风失败，再只改相关输入。不要为了修一列车的位置，顺手重写全部风格提示。

这些仍是研究建议，不是当前已实现的 Skill。不能照抄别人的双色印刷规则或蜡笔修图步骤，来代替莫奈原作分析。

## 七、163 条原作记录的正确用途

现有参考集是 163 条记录，统计中还有 7 条藏所待核实；部分题材和天气标签基于文字规则。它适合检索与比较，不应直接视为 163 个已经完成艺术史核验、相互独立的训练样本。[R1]

进入视觉实验前，先选少量同一候选时期、题材不同的参考，并核查实际画面、原作身份、数字化版本和使用权利。不能把全部年代的作品平均成单一风格，也不能把所有参考图无差别附到每一次请求。

开发集与保留测试集须按**原作身份**分组，而不只按 Commons page ID。相同原作的不同扫描、裁切与翻拍不得跨组，避免误把记住素材当作泛化。未来可增加作品级 group ID；本轮没有修改现有资料集或提前定稿目标时期。

## 八、两条路线，不把 Skill 偷换成模型项目

**模型无关 Skill 路线**：理解需求、选参考、准备生成请求、调用实际支持的工具并验收。封闭 API 只提供文字和参考图时，就如实使用这些接口，不能宣称已经启用其内部层控制或 ControlNet。

**开放模型实验路线**：用 SDXL 与原生 Diffusers 对照全层 IP-Adapter、仅风格层、全局特征相减和内容结构控制。这是验证机制的实验后端，不要求最终 Skill 必须绑定 SDXL、自建 GPU 服务或 ComfyUI。

建议先完成最小对照，再决定反演、CSD、额外语义适配器和 LoRA 是否值得加入。详细执行条件与试验数见 [实验方案](EXPERIMENT_PLAN.zh.md)，所有参数均为待验证候选。

## 九、复现与授权

相同 seed 有助于对照，但不能单独保证跨硬件、软件版本和注意力实现逐像素相同。应一并记录模型／权重 revision、预处理、尺寸、采样器、步数和随机数生成器状态。[S12]

本次固定快照中，IP-Adapter、Diffusers 检出 Apache-2.0；两个 Skill 项目检出 MIT。InstantStyle、InstantStyle-Plus、CSGO 的仓库元数据未检出许可证，递归文件清单也未找到 LICENSE／LICENCE／COPYING 类文件。因而当前只作方法研究，不把这些实现直接复制并改标为本仓库 MIT。[S13]

mono-color 的示例图有独立的素材许可，不能按代码 MIT 自动复用。[S11] 代码、权重、参考图的许可须分别核查。本轮只发布原创研究文本、原创审查脚本和来源索引，不捆绑第三方源码、权重或示例图。
