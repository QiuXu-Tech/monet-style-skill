# 莫奈原作对照评测协议 V1.0

**状态：DESIGNED / NOT_RUN（未出图、未打分）。** 目标是把“照着原作学画法”变成可重复、有反例、不会制造虚假分数的评测程序。本文件是技术评估协议，不是 Monet Skill 的新风格预设。

## 1. 研究的真正问题

**不是**“新图与原画的船、人、草垛数量有多相似”，而是“面对同类题材与光照任务，新图是否具有莫奈作品中可辨识的笔触组织、光色关系与空气感”。

- 内容门槛：至少同一题材类型、相容的时间天气条件、独立单幅画；严重跑题、报告海报、双联画、意外文字直接 FAIL。**内容相似程度不参与风格总分。**
- 主评估：笔触（30%）、色彩（30%）、氛围感（30%）、伪纹理控制（10%），每项 0–10 分，可保留半分。
- 原作中原本存在的短促、破碎笔触**不属于错误**；有问题的是无视天空/水/衣料/地面差异、同尺度重复铺满画面的 AI 鳞纹。
- 多幅作品的朦胧感应随内容变化：画面可以清晰到保留必要主体，却不应统一锐化或对全图做高斯模糊。
- 不强制所有画面模仿相同色板、饱和度和笔触密度。

## 3. 生成时怎样避免照抄名画

1. 先取 `cases.json` 每幅原画对应的 `content_prompt`，固定完整提示、画幅、要求；要求同类场景，但不强求对应原作的物体数量、具体位置或人脸。
2. **原作图像只给评审者看（EVALUATION_ONLY），不作为这幅画的内容图输入。**否则很难区分模型真的有画法能力，还是只照抄了原画的像素、构图与对象。
3. Baseline 与候选 Skill 应使用相同内容提示、同一宿主模型与尺寸，尽可能锁定参数、参考图角色、时间窗口；候选可使用其已冻结的独立 style anchor，但要记录该锚点，不能声称对照只改变某一句提示词。
4. 需要评测独立画风配方时，可增加纯文本配方臂；但这是**另一个预登记实验**，不把方法和条件偷偷改变后的图混进当前比较。
5. 不固定 seed 或模型版本的后端，记录真实可获得字段，按同一时段交错生成；不得伪造精确复现。

**首轮建议：** 3 幅内容题目 × 2 个方案 × 每方案 1 次 = 6 张冒烟样本。确认能产出独立画作并可看图后，才扩大为 3 × 2 × 2 = 12 张（**合计是否重新生成**需在执行前声明），不自动使用付费 API，也不自动批量挑最好的一张。

## 4. 每幅作品的审看顺序

1. **核对图像本身**：确实是生图工具返回的独立画作，非报告、合成拼图或原画复制品；留存模型/调用记录、尺寸、输出 SHA-256。
2. **内容门槛**：题材类别、光照/天气和单幅格式必须通过。未评审填 `null`，看不清记 UNKNOWN，不给正常分。
3. **评审遮蔽**：对候选随机编号，尽量隐藏 Baseline/Skill 版本；以固定的原作参考展示进行人工对照，不让模型先看到哪个是“优化后”。
4. **分别打四维分数**：每项写至少一句具体画面证据，包括颜色/笔触所在区域，而不只是“很像莫奈”。不要把漂亮程度当成画风贴合程度。
5. **记录失败局部**：标注位置（天空、水面、衣物、草地、麦垛），区分重复鳞纹、过度饱和、全部磨糊、色彩关系不自然等。
6. **结果排序**：先看硬性失败数量，再看各维度与加权分、跨题材波动；全部图都保留，不做只挑好图的 best-of-N 作弊。

### 四维评分锚点

| 分数 | 解释 |
|---:|---|
| 0–2 | 明显不符合原画的画法语言、严重机械纹理或无空气组织 |
| 3–4 | 存在一些印象派元素，但更多是滤镜、均匀小碎笔或固定色板 |
| 5–6 | 部分自然，但颜色、笔触、边缘或空间明显偏离 |
| 7–8 | 整体具有可迁移的色彩与绘画逻辑，瑕疵有限 |
| 9–10 | 高度连贯，区域差异、光色空气关系都经得起局部查看 |

分数为**评审意见，不是艺术史鉴定值**；若 `hard_gates` 均通过且四维都有真实评审，则：

`S = 0.30 × 笔触 + 0.30 × 色彩 + 0.30 × 氛围 + 0.10 × 伪纹理控制`

**禁止**仅因为 S 高就宣布“稳定”。每张图还要报告四项原始分、失败区域和分歧。首次试验不预设“分数多少一定可以发布”。

## 5. 单轮优化决策

每次只选一个有证据的缺陷，例如“港口水面的鳞纹密度过高”。随后：

`冻结旧版 → 预登记变更 → 仅改有关规则 → 同题同参数 A/B → 各项评审 → 保留/回滚/不确定 → 收集失败证据`

- **笔触失败**：检查天空/水面/衣物等是否使用同尺度短笔，尝试修改区域级笔触规则，而非全图加粗笔触。
- **色彩失败**：比较高饱和焦点与周围色域的关系，不单纯拉高/压低全局饱和度。
- **氛围失败**：检查边缘消融、远近对比、冷暖层次，避免全图无差别柔焦。
- **纹理失败**：记录鳞纹所在区域及尺度，试最小改动；使用 clean-remake 时不要破坏正确的空气感。
- **内容失败**：先修宿主/内容约束；图片根本不是单幅画的情况视作工具路由错误，而非画风低分。

小样只用于选择下一轮方向，不能当作统计学上的“稳定提升”。晋级后再用不同题材、不同原作的**作品级独立保留集**做验证；原作不同扫描和裁切不得跨开发/保留集。保留集一旦拿来调参，就转为开发集，不能继续用于盲测。

## 6. 记录规范与状态

每张图复制 [review-template.json](review-template.json) 一份，填入真实 `case_id`、输出地址/哈希、使用的模型及能取得的配置、评审人、硬门结果、四维分数及画面证据。若没有生成图片，`generation_performed=false`、四维分数保持 `null`、状态必须是 `NOT_RUN`。

**禁止再次发生**：用信息图代替实际画作、从虚构比较表中产生评分、将尚未测试的结果写成“通过”、把内容与风格相似度混在同一个总分中。

本协议与上层 [优化循环](../../docs/optimization/README.zh.md) 配合使用。本轮只建立真实可执行的评测标准，不修改生成器、锚点、模型或已经保存的原作资料。
