## 设计依据与取舍

此前运行时主要依据两幅1880s参考图，九篇逐画研究没有完整进入日常使用；默认正文仍倾向将空气感写成雾与柔软，也没有明确区分局部笔迹、颜料起伏和选择性完成。完整研究见[原作索引](../research/artwork-studies/README.zh.md)，供独立Skill包使用的证据摘要见[artwork-evidence.md](../skills/monet-style/references/artwork-evidence.md)。

| 研究关系 | 运行时选择 | 适用边界 |
|---|---|---|
| 03、04、06/07：稳定大形与碎笔可共存 | 保留主平面、重量、遮挡与关键动作，局部色迹和次要轮廓允许断续 | 不是推断莫奈统一的实际作画顺序 |
| 02、03、08：同材质内部也有差异 | 联合结构、材质、照明、距离、视觉作用和构图节奏决定笔迹 | 不要求每个区域必须截然不同，也不靠随机变化冒充自然 |
| 03、06/07、08：光改变颜色与可辨细节 | 同时考虑相邻色、反光、局部对比和边缘显著性 | 不规定所有影子蓝紫、所有亮部橙黄 |
| 02、08与1875人物专题：细节并不平均 | 按尺度与作用处理脸手、花群、衣服、天空 | 简略仍须保留姿态、比例、接触和身份要求，不能全图模糊 |
| 01、09：水中整体色域与局部水笔不同层次 | 反射保持来源联系，局部笔迹依水面重组 | 不把所有河流、海浪、冰面都画成同一种横短笔 |
| 04/05：笔迹、起伏与覆盖历史不等同 | 放松统一厚涂，允许较平缓的可见笔迹和局部表面强调 | 不从数字图推定化学成分、毫米厚度或精确层序 |
| 01与03的不同天气：空气感并非都靠雾 | 用色彩、遮挡、尺度、对比和选择性边缘建立空间 | 只在场景需要时加入雾，保留晴光与夜晚 |

两项反例防止把研究变成另一套僵化滤镜：

- [AIC 1922.431 技术专论](https://publications.artic.edu/monet/reader/paintingsanddrawings/section/135603/p-27)同时记载相对统一的表面笔触、低起伏及很少厚涂。整体节奏统一不自动等于机械盖印。
- [NGA 1970.17.45](https://www.nga.gov/artworks/52189-artists-garden-vetheuil)强调近看笔迹的装饰性。因此花点与植物结构保持松散联系即可，不要求每一点都对应完整可描的茎叶。

以上由原作事实/馆方解释和档案视觉观察支持，转成生成要求仍是工程假设。本次复核了部分馆方文字，没有新增高清逐区域重看、实物检查或显微读片；不把旧档案观察冒称为新的看图证据。

## 实际修改

### 1. 核心规则与按需题材指导

- 新默认 `research-v3` 使用 `monet-1880s-research-v3` 契约。
- [style-contract.json](../skills/monet-style/references/style-contract.json)保存唯一核心画法及定性审查项；[subject-modules.json](../skills/monet-style/references/subject-modules.json)保存六个条件模块。
- `garden`、`water`、`figures`、`architecture`、`snow`、`coast` 由助手依原请求显式选用，零至三个；脚本不假装自动理解画面或检测题材。
- `painting_notes` 最多五条，记录未被核心/模块覆盖的局部关系，不把研究标题、评分、固定馆藏布局、颜料配方搬进正文。
- 保留少量核心规则，详细依据按需查阅；不把九篇报告全文塞进每次生成提示。

这些模块是1880s默认下的题材指导，不是六种模型，也不是已经验证的1870s/1890s/晚期睡莲预设。

### 2. 明确提示词、研究、评审和生成四种任务

[SKILL.md](../skills/monet-style/SKILL.md)首先应用会话约束。本项目实际测试图仍由用户另开对话生成；本会话只准备完整文本或审看返回图。准备提示词不要求生图工具、下载参考图或交付TXT/ZIP。

在另一个允许生图的使用场景，才根据当前工具schema映射真实图像输入。禁止凭工具存在就自动生成，也不为补足能力擅自切换付费API或本地GPU。

### 3. 统一正式编译器与评测输入

[monet.py](../skills/monet-style/scripts/monet.py)保留原始请求，编译单幅绘画要求、核心画法、选中模块与局部关系。新正文不再自动加入JSON工作单、版本状态、评分元数据、馆藏标题或锚点对象黑名单。

[generation_preflight.py](../benchmarks/original-paintings-v1/generation_preflight.py)删除另一份独立 `STYLE` 文本，调用同一 `monet.prepare(..., text_only=True)`。这样后续不会发生“更新了Skill，但实际实验还使用另一套画法”的偏差。

纯文本预处理明确：风格参考未附、未生成图片、不能据此声称受控A/B合格。历史 `legacy-v2` 的带元数据包装正文不由本版benchmark伪装成清洁图像请求发出；旧版完整复现使用历史提交。

### 4. 输入记录与真实传图分开

- 工作单保存正文SHA-256及含末尾换行的文件SHA-256。
- 提示文件固定写入UTF-8字节，避免Windows文本换行导致记录哈希与文件不一致。
- 系列锁绑定核心契约、锚点和题材模块库；某次场景选哪些模块、怎样填写局部关系另由request/job哈希记录。
- `style_anchor_prepared`表示本地准备，`style_anchor_attached=false`记录prepare阶段尚未调用宿主。
- 修复text-only搭配cleanup时误把辅助参考当成风格原图的条件判断。
- 每个需要传入的参考角色各有交付检查；未确认时保持unknown，不能达到 `ACCEPTED_REPORTED`。analysis-only原图不强制传入。

这些仍是可审计记录与评审者声明，不是远端附件真实性认证，也不能证明模型实际遵循了参考。

### 5. 原作对照与四维评审

[review.md](../skills/monet-style/references/review.md)定义整幅—区域—局部审看，针对脸手、花群、天空、反射和角落疑似签名提供明确观察方法。

[原作对照协议1.1.0](../benchmarks/original-paintings-v1/README.zh.md)保持四维各0—10分与权重：笔触30%、色彩30%、空气氛围30%、机械鳞纹10%。对应已核实原作是四维10分的定义锚点，人评与模型评独立保存。

新增实际原作复制图来源/文件SHA、馆藏身份与签名/独特构图检查。任何硬门失败或未知，四维分数保持null且无总分；没有生成图或没有实际审看，不补估分数。历史1.0.0记录仍可读，但显式标明未经过新版门禁。

`monet.py review`处理定性检查与记录一致性，不自动识别画面，也不计算四维分数；项目benchmark的校验器根据合格的已填写记录计算加权分。两者职责在文档中明确。

### 6. 现有辅助路线与入口同步

保留cleanup和可选ComfyUI，不新增后端或模型。ComfyUI校验能识别新旧profile，并核对research-v3模块库哈希；仍为dry-run默认，真实推理未执行。cleanup不再被写成每次纹理问题的默认解法。

同步版本、中文使用说明、Skill入口元数据、MANIFEST及项目入口。旧优化流程只增加当前适用范围提示，未回写历史结果。

## 使用入口

普通对话：

> 使用 $monet-style，为晴朗午后的花园人物场景准备一条完整提示词，人物脸手概括但动作清楚。我会另开对话生图。

脚本示例（仓库根目录；仅准备文本）：

```bash
python3 skills/monet-style/scripts/monet.py prepare \
  --request skills/monet-style/examples/garden-figures.json \
  --text-only --out /tmp/monet-garden-001

python3 skills/monet-style/scripts/monet.py prepare \
  --request skills/monet-style/examples/river-evening.json \
  --text-only --out /tmp/monet-river-001
```

用户交付仍为完整可复制文字；工作单、来源与分数不粘入生图正文。针对暂未建立预设的历史时期，先说明范围，再提供有根据的研究性文本，不把1880s配置改名冒充。

## 尚未验证及后续实验

**本次没有真实生成图、视觉A/B、独立人工评分、模型质量提升率或新P5结果。** 不能从125项工程测试、更多文档或参考哈希正确推出画得更像莫奈。

下一次实际比较仍由用户在独立会话执行。先冻结旧/新版本与完整prompt，再以相同内容、画幅、参考交付方式及可知宿主条件比较。优先选择本批1880s关联题材：花园人物的选择性完成、河岸建筑与水面组织、同一草坡的受光/距离变化。保留全部首轮结果与失败，原作作为评审参照，单列人评和模型评。

新版与旧版的整体比较属于**组合更新比较**；不能据此归因于某一句笔触规则。若需要验证某条规则，应另行冻结其他因素，只改一个关系再看实际图片。现有MOR-01/02/03属于跨时期诊断，不自动成为1880s默认的合格证明。

晚期大型睡莲、不同历史阶段的完整预设、现代复杂题材、真实多参考角色控制、反复生成稳定性仍待专项研究或验证。用户本次授权的是研究指导更新；这些未完成事项继续如实保留。
