# V3-W02｜形体构成式笔触修订和对照

**日期：2026-11-19；版本：0.5.0-alpha.2；状态：TEXT/STRUCTURE_VALIDATED，VISUAL_AB_NOT_RUN。**

## 真实观察与诊断

用户提供 V3-G01 花园人物图和 V3-W01 河景图，并明确反馈“色彩确实好看，但感觉不像莫奈；笔触也不像”。V3-W01 天空出现整体等密度细弧纹、水中连续细横笔、右下草坡梳齿短线、杨树叶群过于整齐。整体类似先完成精细数字插画，再加表面油画纹；这是**画面现象的推断**，不是生成器内部工作顺序的实测。此前模型7.2初评并非严格原作锚定，不能用于证明版本水平。

## 定向修改

新版 `research-v3` 契约0.3.1要求以相邻、重叠的颜色笔迹构成体积、光影和部分边缘，允许大面积安静的画面与局部密集笔触共存，避免全幅均匀油画纹。同时保持构图、时间、颜色、人数、动作、物体和画幅不变。此为研究驱动的工程假设，**不声称是莫奈实际作画工序**。

2026-11-18版契约0.3.0原字节保留 `style-contract-v3-20261118.json`，通过显式profile `research-v3-previous` 使用；水面等六题材模块不变，参考锚点不变，V2/P0历史不变。

## 如何比较

使用 [river-w02.json](../skills/monet-style/examples/river-w02.json) 冻结和上一张河景一致的场景与两条区域说明，并分别编译：

```bash
python3 skills/monet-style/scripts/monet.py prepare --request skills/monet-style/examples/river-w02.json --text-only --profile research-v3-previous --out /tmp/w02-old
python3 skills/monet-style/scripts/monet.py prepare --request skills/monet-style/examples/river-w02.json --text-only --profile research-v3 --out /tmp/w02-new
```

唯一核心提示变量是style contract，`water`模块、场景和备注一致。每一臂需在全新独立对话生成一次并保存第一次结果。图像宿主、模型版本、随机种子、实际参考附件需要按真实情况记录未知，不能凭文字声称严格可复现。由于旧V3-W01并无真实编译job，W01→W02不构成严格A/B。

## 预登记检查

| 对象 | 希望观察到 | 同时不得损害 |
|---|---|---|
| 天空 | 云色、光与笔迹参与形成空气，不再整片均匀弧笔 | 不应糊成数码渐变 |
| 树冠 | 色群、透光空隙与轮廓形成树的体量 | 三株杨树不能消失 |
| 河水 | 色块和方向性水笔共同构成反射，亮水/树影节奏不同 | 不产生镜面复制或过分粗糙 |
| 草坡 | 笔触服务光照和坡度，而非梳齿纹 | 保留野花与地形 |
| 全幅 | 笔触看起来像在构成绘画 | 保留用户喜欢的色彩、光与构图 |

继续按笔触/色彩/空气/机械纹理的30/30/30/10评审，原作作为定义性10分参考；无图不打分，不自动称新版本提升。九篇原作及索引、锚点图片和历史实验记录保持原样。本次不调用图像生成工具。
