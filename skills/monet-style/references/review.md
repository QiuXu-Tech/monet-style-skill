# 验收和定向纠错

## 判定边界

脚本只核对工作单/图片哈希、完整检查项、证据是否填写和画幅比（2% 容差）。图片仅作 PNG/JPEG 头与长度检查，仍需要宿主正常解码并查看。`inspected_image` 必须由实际查看动作支持。

检查结果只能是 pass / fail / unknown。看不清、未查看、工具不支持时用 unknown。一个含糊的“很像莫奈”不能代替逐项证据；记录如“左侧红伞人物保留，右侧灰外套人物缺失”。评审者区分 human / model，模型自评不冒充人工或独立盲评。

- REJECTED：至少一项失败，或画幅不满足。
- NEEDS_REVIEW：检查尚未完成或缺少审看信息。
- PROMPT_ONLY_OUTPUT：纯文本降级路线的输出，即使自评通过，也不是参考受控运行。
- ACCEPTED_REPORTED：评审者对这张图报告全部通过。不是自动判画算法，也不是跨任务稳定性结论。

## 原作构图与疑似署名检查（重要）

将“画风相似”和“重构著名原作的可辨识构图”分开判断。即使原作图片没有送入生成模型，模型也可能因文字线索而复现熟悉的构图；这种情况不能作为画法成功迁移的证据。

- 查看生成图片**完整画面与四角局部**，尤其是左下角是否出现画家签名、模仿签名、年份或其他非用户要求的题字。确实出现时对 `reference_leakage` 与相应 `artifacts` 检查标记 `fail`；看不清而疑似文字时标 `unknown`，绝不臆称已经辨认出某位画家的署名。
- 将**主体布置、轮廓、光源位置、倒影方向和特征性前景对象**与已核实原作对照。若它们组合成可辨认的同一名画构图（而用户没有明确要求复刻），则 `reference_leakage: fail`，不纳入可迁移风格的通过样本；若只是同一题材常见元素，应记录差异，不能仅凭一条船或一轮太阳判定复制。
- 区分三种结论：`STYLE_SIMILARITY`、`COMPOSITION_MIMICRY`、`PIXEL_COPY`。从构图相似只能推断第二种风险，不能据此宣称已经进行像素复制或版权侵权。像素复制需要另行可核实的图像比对证据。
- 此项与机械鳞纹评分相互独立：画面再漂亮，只要存在明确的无请求署名或高度特征化的原作构图泄漏，也不得晋级默认画法。保持原始图片与生成回执，记录具体问题区域，不进行遮盖后冒充原始样本的处理。

## 缺陷 → 最小修复

| 缺陷 | 下次操作 |
|---|---|
| 主体、数量、位置错误 | 只强化相应内容要求，支持时编辑该局部；不更换参考 |
| 风格参考的帆船/房屋/人物混入 | 去掉非需求对象，重申参考仅提供画法；不一律禁止用户本来要求的同类对象 |
| 全图摄影感或统一柔焦 | 针对笔触/色块/局部边缘差异纠偏；不要全图套噪声纹理 |
| 夜景变白天 | 保留原要求，明确不继承原作日照与明度 |
| 机械重复的鳞纹、假微纹理、脏渐变 | 优先启用或加强 cleanup route；保留大块光色与结构，不直接对成品再糊一层模糊滤镜 |
| cleanup 之后变成均匀糊图 | 回退高斯辅助权重或停用它；保留结构图，单独强调“空气感 ≠ 统一模糊” |
| 修改后原有正确部分漂移 | 保留原候选及失败记录，重新使用内容图/锚点；不覆盖旧图 |
| 风格输入未被实际附上 | 停止，将能力不足记为 NOT_SUPPORTED；不继续虚构控制效果 |

最多三次实际出图尝试。每次变化记录到任务目录，费用和工具行为遵守用户授权。对整个 Skill 的“稳定性”还需要跨题材、多次重复、保留集和人工评审；本包未完成这项视觉基准。

### 生成后第一道门禁：输出类型

若用户要求单幅绘画，但模型返回了**对比表、报告、图集拼版、摘要卡片或带虚构分数的图**，立即在 `single_painting_canvas` 标记 `fail` 并拒收。该错误不可被其他评分抵消，不要引用任何图中自称的实验结果。
