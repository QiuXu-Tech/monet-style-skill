# 验收和定向纠错

## 判定边界

脚本只核对工作单/图片哈希、完整检查项、证据是否填写和画幅比（2% 容差）。图片仅作 PNG/JPEG 头与长度检查，仍需要宿主正常解码并查看。`inspected_image` 必须由实际查看动作支持。

检查结果只能是 pass / fail / unknown。看不清、未查看、工具不支持时用 unknown。一个含糊的“很像莫奈”不能代替逐项证据；记录如“左侧红伞人物保留，右侧灰外套人物缺失”。评审者区分 human / model，模型自评不冒充人工或独立盲评。

- REJECTED：至少一项失败，或画幅不满足。
- NEEDS_REVIEW：检查尚未完成或缺少审看信息。
- PROMPT_ONLY_OUTPUT：纯文本降级路线的输出，即使自评通过，也不是参考受控运行。
- ACCEPTED_REPORTED：评审者对这张图报告全部通过。不是自动判画算法，也不是跨任务稳定性结论。

## 缺陷 → 最小修复

| 缺陷 | 下次操作 |
|---|---|
| 主体、数量、位置错误 | 只强化相应内容要求，支持时编辑该局部；不更换参考 |
| 风格参考的帆船/房屋/人物混入 | 去掉非需求对象，重申参考仅提供画法；不一律禁止用户本来要求的同类对象 |
| 全图摄影感或统一柔焦 | 针对笔触/色块/局部边缘差异纠偏；不要全图套噪声纹理 |
| 夜景变白天 | 保留原要求，明确不继承原作日照与明度 |
| 修改后原有正确部分漂移 | 保留原候选及失败记录，重新使用内容图/锚点；不覆盖旧图 |
| 风格输入未被实际附上 | 停止，将能力不足记为 NOT_SUPPORTED；不继续虚构控制效果 |

最多三次实际出图尝试。每次变化记录到任务目录，费用和工具行为遵守用户授权。对整个 Skill 的“稳定性”还需要跨题材、多次重复、保留集和人工评审；本包未完成这项视觉基准。
