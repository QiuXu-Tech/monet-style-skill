# 原作对照、验收和定向纠错

本流程评审实际图片。没有图、没有看图或只有提示词时，记录 `NOT_RUN` / `NEEDS_REVIEW`，不推测风格分数。评审不自动触发生图。

## 1. 先确认比较对象

记录生成图、实际查看尺寸、完整画面或裁切、候选标识；能取得文件时记录 SHA-256。生成工具、模型、参考实际传输和设置不可知时写 `unknown` / `undisclosed`。不要为了填满字段伪造调用编号。对用户从独立聊天带回的图片，可直接做人工/模型评审；缺失的宿主信息会限制严格A/B结论，不阻止诚实的局部观察。

选择已核实的对应原作，记录作品名、馆藏号、官方来源、查看的复制图，以及是否同一时期/题材。参考 [artwork-evidence.md](artwork-evidence.md)。不要把1880s预设与1890s原作的差异直接解释成全面失败，跨时期比较应单列范围。区分数字复制图的色偏、分辨率、压缩和画框阴影，不以显示图判断精确颜料厚度。

**本项目将该对应原作定义为笔触、色彩、空气氛围、机械鳞纹控制四维各10分。** 这是风格研究的校准锚点，不是要求复制构图，不是艺术史排名，也不意味着所有原作使用同一种表面或笔触。不得为便于评分另编一套“莫奈原作其实只有8分”的基线。

## 2. 按三个尺度看图

1. **整幅：** 主体数量与动作、明暗大块、构图重心、主要平面、空间深度、天气时间。检查是否单幅绘画，有无报告、拼版或假评分。
2. **区域：** 比较同一材质处于不同坡度、光照、距离和视觉作用时的处理；核对人物和环境、花朵和叶丛、水面和倒影来源之间的联系。
3. **局部：** 查看焦点脸手、花簇/枝叶、天空与地面纹理、四角疑似签名以及关键边缘。小图看不清时明确写 `unknown`，不要用放大插值产生的纹理补充证据。

每维至少给出两个具体区域的证据，说明“在哪里、看到了什么、与原作的哪种关系相符或不同”。不要求为显然不适用的项目虚构区域：例如无人物时说明该项不适用。

## 3. 内容与原创性先过门

| 检查 | 判断依据 |
|---|---|
| 单幅输出 | 不是信息图、对比拼版、评分海报或多个独立构图 |
| 内容、数量、动作、空间关系 | 逐条对照原始请求，不能因画面漂亮忽略对象缺失 |
| 指定光照与画幅 | 夜晚不变白天，晴天不强制起雾；有文件时核对比例 |
| 形体可读性 | 必须保留的姿势、透视和接触关系成立；简略不能掩饰畸形 |
| 参考泄漏 | 检查假签名及独特布局/取景/对象位置组合，不只查“有没有同种树或房屋” |
| 参考交付 | 使用受控参考模式时，需实际传入正确图片和角色的记录；本地存在、URL或文件名不是证据 |

检查值只用 `pass` / `fail` / `unknown`。硬门失败：拒收；硬门未知：等待核验。可描述风格得失，但**不计算有效的加权总分，不登记整体通过**。不要把“看起来构图相近”升级为已证实像素复制；同文件哈希只能证实返回相同字节。

## 4. 四维评分

| 维度 | 权重 | 比较重点 | 不能当成改善 |
|---|---:|---|---|
| 笔触组织 | 30% | 大形与局部笔迹是否共同成立；结构、光照、距离和画面节奏；同材质内部差异；人物完成程度 | 全部短笔变长笔、处处随机、所有地方都粗糙、脸手涂糊 |
| 色彩关系 | 30% | 受光、阴影、环境反色与相邻色关系；保持要求的时间天气；焦点和背景的饱和度联系 | 统一蓝紫绿滤镜、只提升鲜艳度、复制原作调色却改变用户场景 |
| 空气氛围 | 30% | 颜色、边缘、遮挡、尺度和对比形成的空间；必要形体清楚、次要关系选择性融合 | 全面高斯模糊、所有远景发白、强光场景也强制雾化 |
| 机械鳞纹控制 | 10% | 是否出现跨天空/叶片/皮肤无差别的同形、同距、同尺度纹理；是否无视形体和明暗 | 将正常花群、波浪、窗洞的结构性重复当成伪纹理；删除所有短促笔迹 |

每维0—10分，允许小数。只有对应原作与候选都实际查看、四维证据齐全、硬门全部通过时，才计算：

`总分 = 笔触 × 0.30 + 色彩 × 0.30 + 空气氛围 × 0.30 + 鳞纹控制 × 0.10`

10是原作定义锚点；中间分值是有证据的评审判断，没有自动测量的精度保证。不设置一个未经用户认可的总分阈值来宣布Skill成功。严重内容或原创性失败不能被高风格分抵消。

推荐记录：候选/原作身份 → 评审者 `human` 或 `model` → 实际查看说明 → 硬门结果 → 四维分数及逐区域证据 → 总分或暂不评分理由 → 一个最优先改进项。人评和模型评使用独立记录；不要平均后冒称用户分数。

## 5. 脚本结果的含义

`monet.py review`核对工作单/图片哈希、完整检查项、证据填写、次数和画幅比（2%容差）；PNG/JPEG检查主要是头部与长度，实际解码和审看由宿主/评审者负责。它**不自动识别画面、不做材料鉴定、不认证调用回执，也不计算上述四维总分**。

- `REJECTED`：至少一项失败、画幅不满足，或提交了与输入相同字节的文件。
- `NEEDS_REVIEW`：观察或必要记录未完成。
- `PROMPT_ONLY_OUTPUT`：文本路线的返回图被评审者报告通过；仍不是参考受控运行。
- `ACCEPTED_REPORTED`：评审者报告此图检查通过；不证明全系列稳定或新版优于旧版。

项目仓库的[原作对照协议](https://github.com/QiuXu-Tech/monet-style-skill/blob/main/benchmarks/original-paintings-v1/README.zh.md)提供另行记录的四维评分模板及格式校验器。没有实际证据不要填写通过。

## 6. 缺陷只对应最小修复

| 已观察的问题 | 下一次只改什么 |
|---|---|
| 主体、人数、动作错误 | 相应内容关系；保留正确部分与原候选 |
| 同材质各处都机械盖印 | 具体区域的结构、距离、光照和聚散关系，不全图加随机噪声 |
| 花点像贴纸或彩色颗粒 | 花群与茎叶的松散关系、重叠和间隔，不补全每根茎 |
| 脸手过精或与背景脱节 | 按人物尺度收敛细节与局部对比，保留比例、动作和身份要求 |
| 水面像等距鳞纹 | 指定亮水/暗反射等失败区域的组织与反射来源，不把所有水抹平 |
| 形体破碎或建筑失重 | 主平面、重心与关键开口；不要求描全所有轮廓 |
| 参考取景或假签名混入 | 去掉独特布局/署名借用；保留用户本来要求的同类对象 |
| 油画表面像统一奶油、浮雕或噪声 | 单独降低无依据的凸起/纹理密度，保留有用色迹与安静区域 |
| 空气感变成雾罩或糊图 | 回到场景的颜色、边缘和空间关系；cleanup辅助不能成为全图模糊处方 |

只有现有图片存在明确纹理污染、用户需要重绘且工具支持角色分离时，才考虑[clean-remake](clean-remake.md)。它不是每次鳞纹问题的默认解法。每次真实重试需有授权，最多三次；本项目由用户另开会话生成并回传。

## 7. 版本比较边界

本版与旧版的整体比较属于**组合更新比较**，不是对某一笔触规则的单变量因果验证。后续归因实验要固定内容、宿主可知参数、画幅、参考与评审条件，只修改一个因素。原作只供评审时记录真实未附图状态；不能把文本提及锚点写成模型已接收图片。

保留全部首轮结果、失败和未知项，冻结规则与提示哈希；新对话只是减少旧场景干扰，不能证明后端模型/seed固定。A/B/C、P2、P3、P4来自不同样本和条件，不得据历史分数计算本版提升率；P5没有实际图片，不能补造结果。
