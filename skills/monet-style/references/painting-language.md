# 画法参考，而不是题材模板

## 本版的实验范围

首版采用 1882 年《Cliffs at Pourville》和 1888 年《Gardener's House at Antibes》作为两个可选锚点；默认只用后者。它们已经在本轮逐图查看。以下是对数字复制图的视觉观察，不是颜料检测、完整艺术史鉴定或已验证的最优提示词。完整画法文本的唯一来源是 [style-contract.json](style-contract.json)，勿在其他文件维护另一份近义版本。

**Antibes 1888**：屋顶暖色平面和蓝色阴影保持可辨认的形体，树干与枝叶使用不同方向、密度的笔触；画面并不是全面虚化。复制风险：红瓦房、前景树木、远处海面、签名及原构图。

**Pourville 1882**：天空与海面的低对比、较开阔笔触，与近景草木更集中、更厚实的色点形成对照。不能将其解释为所有部位都必须柔焦。复制风险：斜坡、两个人物、帆船数量、海平线位置、签名。

## 把稳定性落实到输入

同一系列固定 profile SHA、anchor ID 和 anchor SHA；用户可以改变主体和天气。不要因为从花园换成高铁站，就切换画家、时期、参考图或重写画法段。也不要把所有图强行调成蓝紫绿。

默认 1880s 范围只是这个 alpha 的工程选择，可在后续盲评后更改。不要声称已覆盖晚期睡莲的大幅抽象性绘画。不同预设需要新版本和独立评测，不是悄悄混合所有 163 条记录。

夜景、严格文字、精密建筑图、强照片身份锁定等请求可能与此预设发生张力；保留用户硬要求，报告真实失败，不擅自把任务改简单。艺术表达不是事实对象缺失的借口。
