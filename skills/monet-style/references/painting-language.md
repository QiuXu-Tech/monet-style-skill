# 从原作研究到画面决策

本文件解释如何使用 `research-v3`。生成正文的唯一核心来源为 [style-contract.json](style-contract.json)，按题材补充的唯一来源为 [subject-modules.json](subject-modules.json)。逐画来源与反例见 [artwork-evidence.md](artwork-evidence.md)。以下方法属于**研究指导的工程设计，生成效果待验证**。

## 先保持画面的关系

把大形体、局部笔迹和表面起伏分别考虑。建筑的主平面可以连贯，边界和内部色斑可以断续；人物可以简略，但头身比例、持物动作和接地仍应读得出。不要靠连续描边保证形体，也不要靠破坏形体表现“印象”。

将“笔触取决于材质”扩展为：**结构、材质、光照、距离、视觉重要性、构图节奏与可见层次共同影响笔触选择**。这是工作假设，不是莫奈公式。允许某幅画整体节奏接近；避免的是无视这些关系的重复盖印。

## 一个简短的画面计划

在准备提示词前，识别三至六个有意义的区域；简单场景可以更少。只为会影响决策的区域做区分，不建立任意网格。

| 要判断的关系 | 实际问题 | 可写入的决定 |
|---|---|---|
| 形体与遮挡 | 哪些大形、主平面、接触点必须清楚？ | 保留人物持伞的接触关系；次要衣褶可以合并 |
| 光照与可见性 | 何处受光、转折、被遮蔽？什么细节因此突出？ | 让受光花簇与暗叶丛的边缘、对比不同，而不只改变色温 |
| 距离与尺度 | 同一种植物在近、中、远景怎样改变？ | 近处花簇保持少数方向性细节，远处以相关色群组织 |
| 笔触与节奏 | 哪些地方聚集、稀疏、转向或安静？ | 茎的方向与花头色群有关；道路留出较连续的光色面 |
| 注意力与完成度 | 谁是主角？哪些细节只起尺度或环境作用？ | 小人物脸手不做微型肖像，但姿态和解剖不含糊 |
| 表面与空间 | 笔迹是否可见？表面起伏是否必要？ | 用可见色迹而非全图凸起颜料模拟油画 |

将最关键且未被核心规则覆盖的关系写成不超过五条 `painting_notes`。不要把这张表逐项塞进生成提示，也不要宣称它是艺术家的实际作画顺序。

## 按题材调用，按场景修改

| 模块 | 应关注 | 不应机械套用 |
|---|---|---|
| `garden` | 花群、茎叶与遮挡；路径或地面透视；色点聚散和间隔 | 每朵花都完整描出；每个色点必须接上一根茎；凭空添加花园路径 |
| `water` | 反射来源的位置/色块与水面重新组织；亮水和暗影差异 | 严格镜像；全水面同一种波纹；把平静河流横笔推广为所有海浪 |
| `figures` | 体量、姿势、服装、动作与环境同一光照；按尺度分配脸手细节 | 风景小人物精度套给近景主角；全图糊脸；以解剖错误代替简略 |
| `architecture` | 主平面、开口和透视；光照改变局部细节可辨程度 | 建筑每条边都描全；把现代楼宇替换成教堂 |
| `snow` | 地面光影大块与邻近反色；可见笔迹和厚度独立 | 所有雪都纯白、所有影子紫；堆满统一奶油状厚涂 |
| `coast` | 草坡的坡向、距离、受光、轮廓；陆海天空色域联系 | 复制某幅原作的斜坡、人物和地平线；海岸一律雾化 |

一次选择零至三个与原请求相符的模块。含有人物的花园通常用 `garden` 与 `figures`；有岸边建筑和倒影的河景可用 `water` 与 `architecture`。没有对应元素时不要使用模块，也不要用负面词引入锚点物体名称。

模块中的水面、雪景和建筑规则含跨时期研究启发，**不是**1870s或1890s专属画法配置。相同1880s核心下应用这些通用关系仍属于待验证迁移。

## 光色、空气和表面：避免三种替代

1. **不要用全局冷暖滤镜替代光照。** 保留用户时间与天气；让相邻色、反射光、转折与阴影共同影响局部明度、色相和边缘。影子不必全部蓝紫，亮部不必全部橙黄。
2. **不要用雾与模糊替代空间。** 尺度、遮挡、对比和颜色关系可以在晴朗强光下形成空气感。只在场景需要时加入雾；远景也不必一律发白。
3. **不要用厚涂噪声替代油画。** 笔迹明显、颜料起伏大、覆盖层次多是不同事情。普通照片不足以证明精确厚度或作画顺序，不把老化、裂纹、反光、扫描纹理写成风格要求。

## 默认范围与历史配方

默认 `research-v3` 主要依据1881、1882、1888研究，保持 `antibes-1888`。`pourville-1882`为显式备选。锚点只影响画法，不授权复制具体房屋、植物、人物、船只、布局或签名，也不授权覆盖用户的天气与现代物体。

`legacy-v2`保存旧核心正文，便于对照；P0只与此旧配置搭配。新版是组合规则更新，不是旧P0通过实测后的晋级。换版本要新建系列锁，保留旧提交与旧分数。

1870s、1890s可以依据已有报告开展独立研究与明确标注的文本探索；当前没有受验证的对应年代生成预设。晚期大型睡莲尚未完成这批原作研究。现代城市、室内静物和夜景也不能仅因可编译就声称已获得历史作品验证。
